## About Me

I'm a Computer Science and Business Systems student at Kolhapur Institute of Technology’s College of Engineering. I enjoy building practical applications, exploring new technologies, and solving problems through software development.

My work focuses on building applications that combine language models, information retrieval, and conversational interfaces. I enjoy understanding how different components work together, from data processing and retrieval to backend development and application design.

### Projects

**AI Debate Agent System**

A multi-agent debate application designed to generate arguments, research supporting information, and evaluate debates through specialized agents. I built the orchestration workflow using LangGraph and LangChain, exposed the application through FastAPI, and integrated voice interaction using Deepgram for speech-to-text and ElevenLabs for text-to-speech.

*Technologies:* Python, FastAPI, LangGraph, LangChain, Deepgram API, ElevenLabs API

**Nyayavani — RAG-Based Legal Chatbot**

A multilingual legal assistant designed to make Indian legal information more accessible in English, Hindi, and Marathi. I built a Retrieval-Augmented Generation pipeline using ChromaDB and multilingual Sentence Transformers to retrieve relevant legal passages. I also implemented Cross-Encoder reranking to improve context selection and evaluated the system using RAGAS.

*Technologies:* Python, LangChain, ChromaDB, Sentence Transformers, Cross-Encoder, LangSmith, RAGAS

**YouTube Comment Sentiment Analysis Using BERT**

A sentiment analysis system that processes real-world YouTube comments to identify audience sentiment. I used the YouTube Data API to collect comments and developed a multilingual BERT-based classification pipeline with text preprocessing, tokenization, and model evaluation.

*Technologies:* Python, BERT, Hugging Face Transformers, Pandas, Scikit-learn, YouTube Data API

**ARGO Float Conversational Data Explorer**

A conversational application for exploring oceanographic datasets containing measurements such as temperature, salinity, pressure, and geographical coordinates. The project involved processing scientific data and making it easier to explore through natural-language queries.

*Technologies:* Python, xarray, RAG, vector databases, data visualization tools
